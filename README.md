# Crossing Belgium 2026 · Team roadbook

Een mobiele, statische raceplanner voor 12–15 november 2026. De officiële roadbook bepaalt de etappes, locaties en regels; de teamplanning bepaalt de assistenten. Open `index.html` lokaal of publiceer de bestanden via GitHub Pages.

De inhoud staat in `app.js`, de opmaak in `style.css`. Kaartknoppen openen Google Maps. Tijdstippen en locaties die niet in de aangeleverde roadbook vermeld zijn, blijven open. Controleer altijd de laatste aanwijzingen van de organisatie.
